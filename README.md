# Minhas Horas

PWA estática, sem build, para controle pessoal das horas da semana. Os dados ficam só no aparelho (localStorage).

- Ver localmente: `npm run serve` e abrir http://localhost:4173/
- Testes (Playwright, Pixel 7): `npm install`, `npx playwright install chromium`, `npm test`
- Prints das telas: `tests/prints/`
- Ao mudar arquivos do app, subir `CACHE` em `sw.js`.

Decisões e regras: ver `CLAUDE.md`.
