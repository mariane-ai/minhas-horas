# Registro de horas — Girassol

PWA pessoal para registrar horas de prestação de serviço (PJ) no Restaurante Girassol.
Next.js (App Router) + Supabase + Vercel, login Google, pt-BR.

- Regras do projeto, modelo de dados e andamento: [`CLAUDE.md`](CLAUDE.md)
- Como configurar Supabase, Google e Vercel: [`docs/configuracao.md`](docs/configuracao.md)

```bash
npm install
npm run dev
npm test
```
